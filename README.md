# Polymarket 5-Minute Up/Down Bot

Экспериментальный бот для торговли **5-минутными** Up/Down рынками на
Polymarket по 6 активам (BTC, ETH, SOL, BNB, HYPE, XRP) параллельно — 6
независимых потоков. Это **форк** основного 15-минутного бота — та же
кодовая база, стратегия и весь риск-менеджмент, но специально урезанная
до одного таймфрейма: 15-минутные и часовые профили физически удалены
(не просто выключены), чтобы держать этот проект узким и понятным.

**⚠️ Параметры для 5-минутного таймфрейма — НЕПРОВЕРЕННЫЕ ДОГАДКИ.**
Основной 15-минутный бот откалиброван на 961 реальной сделке другого
трейдера плюс на живых 4-часовых отчётах за несколько дней реальной
торговли. Для 5-минутного рынка такой калибровки не делали — параметры
в `src/timeframes.py` просто пропорционально пересчитаны (короче период
ATR/EMA, уже окно входа) из того, что сработало на 15-минутке. Держи
бота в `DRY_RUN=true` и присматривайся к первым отчётам особенно
внимательно — вполне возможно, что для 5-минутного рынка потребуется
другая настройка.

**⚠️ Это торговый бот с реальными деньгами** (когда `DRY_RUN=false`).
Рынки Up/Down устроены как бинарные ставки: выигрыш ограничен ценой
входа, а проигрыш — это полная потеря ставки. Даже "безопасный" вход по
0.90 означает, что в среднем на дистанции нужен винрейт выше ~90%, просто
чтобы выйти в ноль после комиссий и проскальзывания.

## Чем 5-минутный рынок отличается от 15-минутного

- **Слаг рынка** — тот же формат, что у 15m: `{asset}-updown-5m-<unix_ts>`,
  детерминированно вычисляется по чистой UTC-сетке (в отличие от часовых
  рынков, которые привязаны к Eastern Time и в этом проекте не
  реализованы вообще).
- **Индикаторы короче**: ATR(7)/EMA(3,7) на 1-минутных свечах вместо
  ATR(14)/EMA(9,21) — пропорционально более быстрому рынку.
- **Окно входа уже**: 1.0–3.5 минуты из 5 (вместо 2–9 из 15).
- **Опрос чаще**: раз в 3 секунды вместо 5 — рынок живёт втрое меньше,
  нужна более частая проверка.
- Всё остальное — safety score (distance/trend/volatility/time/liquidity
  с MACD как третьим голосом за тренд), жёсткие условия по времени/
  дистанции/волатильности, стоп-лоссы, отчёты, слежка за кошельком —
  без изменений, тот же механизм, что и в 15-минутном боте.

## Как это работает (кратко)

1. Определяем активный 5-минутный рынок по каждому активу.
2. Считаем ATR(7), EMA(3/7), MACD(12/26/9) на 1m-свечах Binance.
3. Safety score (0–100) из пяти факторов; вход требует одновременно:
   цена в диапазоне `[MIN_ENTRY_PRICE, MAX_ENTRY_PRICE]`, score выше
   порога, время внутри окна, дистанция выше минимума, волатильность не
   аномальная — все четыре последних условия жёсткие, не просто вклад в
   сумму (это исправленный баг из истории 15-минутного бота: раньше
   сильный сигнал по одному фактору мог перевесить полный провал по
   другому).
4. Вход — market BUY с исполнением FOK, с проверкой реальной глубины
   стакана перед отправкой.
5. Резолюция — общая фоновая задача сверяется с Gamma API, шлёт итог в
   Telegram.

## Установка

```bash
git clone <твой-репозиторий>
cd polymarket-5m-bot
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:
- `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` — **обязательно ДРУГОЙ бот**,
  не тот же токен, что у основного 15-минутного бота (Telegram не даёт
  опрашивать один токен из двух процессов одновременно). Новый бот — через
  [@BotFather](https://t.me/BotFather).
- `POLY_PRIVATE_KEY` — только когда будешь готов к LIVE; для DRY_RUN не
  обязателен.
- `WALLET_TRACK_ADDRESS` — по умолчанию тот же адрес, что отслеживает
  основной бот. Он торгует 15-минутные рынки, так что уведомления о нём
  здесь будут не по теме этого проекта — можно выключить кнопкой
  🐋 Слежка за кошельком → 🔔 Уведомления в `/menu`, если не нужно.

## Запуск

```bash
python -m src.main
```

Деплой на Coolify/Render/Docker — так же, как у основного бота (см.
`Dockerfile`, `render.yaml`). **Обязательно подключи постоянный volume**
на `/app/data` — без него настройки (кнопки в Telegram) и история сделок
стираются при каждом пересоздании контейнера.

## Управление из Telegram

Те же кнопки, что у основного бота: старт/стоп, активы, размер позиции
(фикс или % от банка), стоп-лосс/день, стоп-лосс позиции, диапазон входа,
настройки (safety score порог), слежка за кошельком/копитрейдинг,
статистика с разбивкой по токенам.

## Структура проекта

```
config.py                    — настройки из .env
src/
  timeframes.py               — единственный профиль: 5m
  binance_feed.py              — цена и свечи с Binance
  market_discovery.py          — поиск активного 5m-рынка на Polymarket
  indicators.py                 — ATR, EMA, MACD, детект волатильности
  strategy.py                   — safety score и решение о входе
  polymarket_client.py          — обёртка над polymarket-client SDK
  storage.py                     — SQLite: сигналы и сделки
  telegram_notify.py             — уведомления и кнопочное меню
  executor.py                     — исполнение входа + резолюция сделок
  reporting.py                     — периодические CSV-отчёты
  runtime_state.py                 — настройки, регулируемые кнопками
  book_stream.py                    — живой WS-стакан
  wallet_tracker.py                  — слежка за чужим кошельком
  main.py                             — оркестрация: поток на каждый актив
```

## Исследовательский модуль: контрольные точки цены (momentum_tracker)

Отдельно от торговли — `src/momentum_tracker.py` НЕ покупает и не
продаёт, только наблюдает. Отслеживает более дорогую сторону каждого
активного рынка и, как только её цена входит в диапазон 0.70-0.95,
логирует полный снимок (RSI, MACD, ATR, EMA, полосы Боллинджера, объём,
дисбаланс стакана) при каждой пройденной контрольной точке (шаг 0.05).
После резолюции рынка каждая запись помечается итоговым исходом. Раз в
`REPORT_INTERVAL_HOURS` — отдельный `*_momentum.csv` в Telegram.
Включается/выключается через `MOMENTUM_TRACKER_ENABLED` в `.env`.

Идея (проверяем на данных, не сразу торгуем): если цена стороны надёжно
проходит путь 0.70→0.80 внутри одного окна, можно купить по 0.70,
дождаться роста, докупить противоположную сторону подешевевшей и
зафиксировать прибыль независимо от исхода — но комиссия тейкера на
каждую ногу (7% для крипто-рынков) съедает часть маржи, это тоже нужно
учитывать при оценке реальной выгоды.

## Дальнейшая калибровка

Как и с 15-минутным ботом — присылай 4-часовые отчёты (CSV с сигналами и
сделками) для разбора. Методика та же: смотрим реальный винрейт против
подразумеваемого ценой, ищем, какие компоненты score реально предсказывают
исход именно на 5-минутном рынке (может оказаться, что здесь работает
иначе, чем на 15-минутном — не переноси выводы 1-в-1 без проверки).
